# OutSystems UI — CSS-only components, layout partials and helper classes

Three kinds of styles without TypeScript behaviour, each with a different contract. Read the group intro before using its entries.

## Components

CSS-only components: no TypeScript behaviour. Emit the markup and classes below and the compiled stylesheet does the rest. Skeletons come from the Storybook stories; `--osui-*` knobs are the per-instance overrides. A component marked **host-styled** is a layer another pattern creates (a balloon): adjust it through its knobs only.

## Layout partials (host-styled)

They style markup that something else emits: the app template Layout and Menu blocks, the Login common screen or the platform runtime. Never generate that markup: place content in the host placeholders and adjust the look through the knobs listed.

### content (src/scss/02-layout/_content.scss) — host-styled
Markup emitted by: app template Layout blocks. the .content region and its title/actions rows are placeholders of the Layout block. Do not generate this markup.

### header (src/scss/02-layout/_header.scss) — host-styled
Markup emitted by: app template Layout blocks. the header is a placeholder group of the Layout block. Do not generate this markup.

### header-layout-native (src/scss/02-layout/_header-layout-native.scss) — host-styled
Markup emitted by: app template Layout blocks (native). header variant of the native layout. Do not generate this markup.

### header-layout-side (src/scss/02-layout/_header-layout-side.scss) — host-styled
Markup emitted by: app template Layout blocks (side menu). header variant of the side-menu layout. Do not generate this markup.

### ios-bounce (src/scss/02-layout/_ios-bounce.scss) — host-styled
Markup emitted by: platform runtime (iOS). a fix applied to the native layout by the runtime; no markup of its own. Do not generate this markup.

### layout (src/scss/02-layout/_layout.scss) — host-styled
Markup emitted by: app template Layout blocks. the screen layout skeleton (.screen-container > .layout) comes from the template's Layout block. Do not generate this markup.
CSS API: --osui-layout-main-padding --osui-layout-aside-lines

### layout-section (src/scss/02-layout/_section.scss)
Layout classes applied to the app template's containers: full-width-section ThemeGrid_Container section-background section-content

### login (src/scss/02-layout/_login.scss) — host-styled
Markup emitted by: app template Login common screen. the login screen and its form come from the template's common screen. Do not generate this markup.

### menu (src/scss/02-layout/_menu.scss) — host-styled
Markup emitted by: app template Menu block. the application menu container and overlay come from the Menu block. Do not generate this markup.

### menu-app-login-info (src/scss/02-layout/_menu-app-login-info.scss) — host-styled
Markup emitted by: app template Menu block. the signed-in user block is part of the Menu block. Do not generate this markup.

### menu-app-menu-links (src/scss/02-layout/_menu-app-menu-links.scss) — host-styled
Markup emitted by: app template Menu block. the navigation links are generated by the Menu block from the app's screens. Do not generate this markup.

### menu-header-logo (src/scss/02-layout/_menu-header-logo.scss) — host-styled
Markup emitted by: app template Menu block. the logo slot is part of the Menu block. Do not generate this markup.

### menu-layout-native (src/scss/02-layout/_menu-layout-native.scss) — host-styled
Markup emitted by: app template Menu block (native). menu variant of the native layout. Do not generate this markup.

### menu-layout-side (src/scss/02-layout/_menu-layout-side.scss) — host-styled
Markup emitted by: app template Menu block (side menu). menu variant of the side-menu layout. Do not generate this markup.

### pull-to-refresh (src/scss/04-patterns/06-utilities/_pull-to-refresh.scss) — host-styled
Markup emitted by: platform runtime (native). the pull indicator is injected by the platform runtime. Do not generate this markup.

### themegrid-container (src/scss/02-layout/_themegrid-container.scss) — host-styled
Markup emitted by: app template Layout blocks. the grid container wraps header, content and footer placeholders of the Layout block. Do not generate this markup.
