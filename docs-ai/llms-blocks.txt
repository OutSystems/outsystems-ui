# OutSystems UI — block reference cards (OML producers)

One card per composable OutSystems UI block, from the OML (OutSystemsUI ODC 13.1421.9.60000). Compose blocks with these signatures; never emit a pattern's markup or lifecycle calls — the block does that. Values for an `<Entity> Identifier` come from osui.enums.json; classes for ExtendedClass (Text on purpose) from llms-utilities.txt. An optional parameter shows its default: the OML's, else the platform default of its data type.
