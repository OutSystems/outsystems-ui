One card per pattern. Signatures, props, defaults and allowed values are generated from the TypeScript source; markup skeletons come from the Storybook stories that drive the compiled bundle exactly as the platform does.

Props (configs JSON, always include "ExtendedClass": ""):
- AutoPlay: boolean = false — Advances the slides automatically.
- Direction: GlobalEnum.Direction.LTR | GlobalEnum.Direction.RTL | GlobalEnum.Direction.TTB — Slide direction: ltr, rtl or ttb (vertical).
- Height: string | number = "auto" — Height of the carousel (CSS length or pixel number); auto by default, required for the vertical direction.
- ItemsDesktop: number = 1 — Number of items visible at once on desktop.
- ItemsGap: string | number = "0px" — Gap between items (CSS length or pixel number); 0px by default.
- ItemsPhone: number = 1 — Number of items visible at once on phones.
- ItemsTablet: number = 1 — Number of items visible at once on tablets.
- Loop: boolean = true — Rewinds to the first item after the last one.
- Navigation: 'both' | 'arrows' | 'dots' | 'none' = "both" — Navigation controls to render: Arrows, Dots, Both or None.
- Padding: string | number = "0px" — Padding on both ends of the track so neighbouring items peek in (CSS length or pixel number).
- StartingPosition: number — Zero-based index of the item shown first.
