# OutSystems UI — utility classes

Scope: OutSystems UI ships a single token-based theme (light, plus the generated dark mode under class os-dark-theme on <html>). The pre-migration "classic" CSS snapshot under classic-theme/ is a Storybook comparison artifact, not a target for generated code.

538 classes in 24 families, generated from src/scss/05-useful and the design tokens. Machine-readable, with every declaration: osui.utilities.json (schema/osui.utilities.schema.json).

## Grammar

- Name: <property>[-<side>][-<value>], long-form, no abbreviations (margin-top-base, display-flex, justify-content-space-between). Tailwind-style short names (p-4, mt-2) do not exist.
- Property heads: margin padding display flex-direction flex-wrap flex justify-content align-items align-content align-self gap row-gap column-gap background text font-size font border-radius border-size border shadow position overflow width height white-space shape.
- Sides: top bottom left right (left/right compile to the logical inline-start/inline-end) · x = inline · y = block.
- Steps, the size scale: none xs s base m l xl xxl. Values: none = --token-scale-0 (0px) · xs = --token-scale-100 (4px) · s = --token-scale-200 (8px) · base = --token-scale-400 (16px) · m = --token-scale-600 (24px) · l = --token-scale-800 (32px) · xl = --token-scale-1000 (40px) · xxl = --token-scale-1200 (48px).
- Colours: background-<hue>[-<shade>] and text-<hue>[-<shade>]; hues: blue cyan grape green indigo lime orange pink red teal violet yellow primary secondary error info success warning; shades: lightest lighter light dark darker darkest (no suffix = base). Neutrals are numbered: background-neutral-<0..10>[-lightest], text-neutral-<0..10>[-darker].
- Responsive: no prefixes. The runtime sets phone / tablet / desktop on <body>; write `.phone .x { … }` for a viewport rule. Only phone-full-width and tablet-full-width ship as viewport helpers.
- A row with {placeholders} stands for every combination of the listed values (margin-{side}-{step} → margin-top-xs, margin-x-base, …). A row without braces is one class. [legacy name] marks a name outside the grammar.
