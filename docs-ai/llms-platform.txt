# OutSystems UI — platform context (ODC documentation)

Human documentation for the concepts this library does not define. Load a page only when a card is not enough; each is 1–3k tokens. Pattern pages: https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/patterns/<category>/<slug>/ — the `Docs:` line of a card gives the slug.

## Concept pages
- User interface (overview) — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/
  OutSystems UI is the responsive, WCAG-compliant framework behind every ODC app: screen templates, UI patterns dragged from the ODC Studio toolbox, and a theme whose CSS rules colours, headings, margins and paddings. Right-to-left layouts are supported.
- Screens — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/screens/
  A screen is composed of blocks and placeholders. A new empty screen uses the LayoutTopMenu block from the Layouts flow, with the placeholders Header (sign-in logic), Breadcrumbs, Title, Actions, MainContent and Footer; template screens may use other layout blocks. Placeholders render only when they hold content.
- Reuse UI (blocks) — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/reuse_ui/
  Blocks are reusable interface + logic units placed on screens or inside other blocks. A block talks to its parent through events (with payload); a parent drives a child through its input parameters; siblings combine both through the parent.
- Themes — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/themes/
  A theme owns the style sheet, icon library and grid settings (columns, gutter, min/max width, layout). Every app has a default theme that inherits from a base theme, most often the OutSystems UI base theme; branding is custom CSS on top (colours, fonts, spacing, CSS variables per light/dark context). The Theme Editor generates that CSS from primary/secondary colour, font and font size. A theme library shares themes, layouts and images across apps.
- Screen templates — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/screen_templates/
  Predefined layouts, widgets, patterns, styles and logic with sample data; drop an entity on a widget to replace the sample data and ODC Studio adapts the UI.
- Accessibility — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/accessibility/
  Set the layout's EnableAccessibilityFeatures to True for focus states, skip-to-content and enhanced contrast. Give every screen a title, every image an alt (empty for decorative), bind each Label to its input, build heading structure with HTML Element widgets (h1…), and use ARIA for dynamic content; SetAccessibilityRole, SetAriaHidden, SetFocus and ToggleTextSpacing are the client actions. The skip target defaults to MainContentWrapper. The patterns accessibility reference lists the roles each pattern applies.
- UI patterns accessibility reference — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/accessibility/ui_patterns_accessibility_reference/
  Per-pattern ARIA notes, e.g. Alert uses role alert for Error/Warning and status for Success/Info; Master Detail needs tabindex and MasterDetailSetContentFocus.
- Icon widget reference — https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/user_interface/screens/icon_widget_reference/
  The Icon widget and its libraries (Phosphor, Font Awesome); the generated classes are listed in osui.icons.json.

## Pattern catalogue (documentation name → runtime card)
The ODC toolbox groups patterns in six categories; a documented pattern maps to a TypeScript pattern (a card in llms-components.txt) or a CSS-only component (llms-patterns.txt). Format: Name (slug) → runtime card(s).
- Adaptive: Columns (columns) → columns · Display on Device (display_on_device) → platform widget / other library · Gallery (gallery) → Gallery · Master Detail (master_detail) → master-detail
- Content: Accordion (accordion) → Accordion + AccordionItem · Alert (alert) → alert · Blank Slate (blank_slate) → blank-slate · Card (card) → card · Card Background (card_background) → card-background · Card Item (card_item) → card-item · Card Sectioned (card_sectioned) → card-sectioned · Chat Message (chat_message) → chat-message · Flip Content (flip_content) → FlipContent · Floating Content (floating_content) → floating-content · List Item Content (list_item_content) → list-item-content · Section (section) → section · Section Group (section_group) → section · Tag (tag) → tag · Tooltip (tooltip) → Tooltip · User Avatar (user_avatar) → user-avatar
- Interaction: Action Sheet (action_sheet) → action-sheet · Animate (animate) → animate · Animated Label (animated_label) → AnimatedLabel · Bottom Sheet (bottom_sheet) → BottomSheet · Carousel (carousel) → Carousel · Date Picker (date_picker) → DatePicker · Date Picker Range (date_picker_range) → DatePicker · Dropdown Search (dropdown_search) → Dropdown · Dropdown Tags (dropdown_tags) → Dropdown · Floating Actions (floating_actions) → floating-actions · Input with Icon (input_with_icon) → input-with-icon · Lightbox Image (lightbox_image) → lightbox-image · Month Picker (month_picker) → MonthPicker · Notification (notification) → Notification · Range Slider (range_slider) → RangeSlider · Range Slider Interval (range_slider_interval) → RangeSlider · Scrollable Area (scrollable_area) → scrollable-area · Search (search) → Search · Sidebar (sidebar) → Sidebar · Stacked Cards (stacked_cards) → stacked-cards · Time Picker (time_picker) → TimePicker · Video (video) → Video

- Numbers: Badge (badge) → badge · Counter (counter) → counter · Icon Badge (icon_badge) → icon-badge · Progress Bar (progress_bar) → Progress · Progress Circle (progress_circle) → Progress · Rating (rating) → Rating
